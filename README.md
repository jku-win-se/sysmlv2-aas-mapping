## Original context

This repository was the artefact associated with the workshop paper:

> **Towards Interoperable Digital Twins: Integrating SysML into AAS with Higher-Order Transformations**
> Enxhi Ferko, Luca Berardinelli, Alessio Bucaioni, Moris Behnam, Manuel Wimmer
> *Workshop/Conference paper (precursor to the JSS 2026 journal article)*

It contained an early version of the AAS Ecore metamodel (Eclipse EMF plugin)
used to explore the SysML v2 → AAS mapping approach.
